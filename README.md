# SNEK SOULS

## Game Description

SNEK SOULS is a quick-paced arcade snake game where the player moves the snek around a looping square arena, eating food blocks that give the snek size and score, and dodging its body as the snek moves forward in time. This game gets increasingly harder as you progress with your score.

## Gameplay

The player can move around the grid and collect food blocks to get higher scores. The objective is to reach a certain score before dying.

## Control Scheme

### Key Controls

* Move Up: ↑
* Move Down: ↓
* Move Left: ←
* Move Right: →

### Touch Controls

* Move Up: Swipe Up
* Move Down: Swipe Down
* Move Left: Swipe Left
* Move Right: Swipe Right

## Features

* Classic Snake Game Design with Modern Graphics
* Score-Based Progression
* Difficulty Increases with Score Increase
* Swipe Support for Mobile Devices
* Keyboard Control
* Colorful Dynamic Backgrounds
* CSS Grid-Based Gameboard
* Restart and Game Over System
* Modal Animation Start Screen

## Built With

* Engine: HTML5 Grid & DOM Rendering
* Programming Language: JavaScript
* Styling: CSS
* Platform: Web Browser

## Getting Started

1. Download or Clone Repository
2. Open `index.html` on a Modern Web Browser
3. Tap Start Button and Start Collecting Souls
